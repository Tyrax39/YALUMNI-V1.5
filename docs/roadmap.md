Status: started.

- Monorepo.
- FastAPI health/status.
- Next.js public/member/admin shell.
- Docker Compose.
- CI.
- Docs.

- User/session models.
- JWT access and refresh tokens.
- Register/login/logout.
- Email verification.
- Password reset.
- Role baseline.
- Protected web route behavior.

- Profile model.
- Program affiliation model.
- Visibility settings.
- Verification requests and documents.
- Admin verification queue.

- Alumni listing.
- Search and filters.
- Profile detail.

- Saved searches later.

## Phase 5: Communities

- Community model.
- Membership and join requests.

- Community detail pages.
- Private content gates.

## Phase 6: Feed And Moderation

- Posts, comments, reactions.
- Reports.
- Moderator actions.
- Admin moderation queue.

## Phase 7: Messaging And Notifications

- Message list/send.

## Phase 8: Events

- Events.
- RSVPs and registrations.
